# Auditoria e evidências

Cada processo registra eventos de criação/edição, geração de documento e abertura de contestação. Eventos não podem ser atualizados nem removidos por trigger. Versões do documento guardam snapshot e hash SHA-256 do conteúdo estruturado. Isso demonstra os dados usados pelo ASA Conecta após a gravação, mas não comprova sozinho o que foi digitado antes do primeiro salvamento nem a autenticidade institucional. Anexos, hash de binários, trilha de acesso a cada arquivo e retenção avançada permanecem pendentes.
